# CipherLab

## Project Overview

CipherLab is a simple Python-based Caesar Cipher Encryption Tool.

It allows users to encrypt and decrypt messages using a shift value. 
The project demonstrates the basic concept of substitution-based encryption.

## Features

- Encrypt text messages
- Decrypt encrypted messages
- User-defined shift value
- Supports uppercase and lowercase letters
- Preserves spaces and special characters
- Simple command-line interface

## Technologies Used

- Python 3
- Python built-in functions

## How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python caesar_cipher.py
```
5. Enter your message and shift value.
6. Select encryption or decryption.
